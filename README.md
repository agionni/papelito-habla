# Papelito habla

Un juego de cartas sobre el silencio del SAT. Es el prototipo de la guía ciudadana interactiva del proyecto de mejora *Fisco Claro y Oportuno*, hecho para la experiencia educativa Derecho Fiscal (Facultad de Ciencias Administrativas y Sociales, Universidad Veracruzana), noviembre de 2026.

Juega en https://agionni.github.io/papelito-habla/

El caso de Elena es ficticio. Las reglas jurídicas son reales y se citan con su artículo, pero no sustituyen la asesoría de un profesional. La página no usa cookies ni envía datos a ningún servidor: todo corre en el navegador.
